# Seeds

Notes for future backpacks that don't have a repo yet. When one starts:
1. Create its repo in the Escape-Backpack org and clone it next to `backpack-kit`.
2. Run `python backpack-kit/kit.py init <Folder> --name "<Name>"`.
3. Turn the seed notes into records (usually `premise` ideas and `question`s), then delete the seed file.
